Tailscale is a tool for connecting devices into a private, encrypted mesh network.

This allows for secure routing, and for example viewing a local only monitoring home dashboard from your phone in a coffee shop securely.

It's very simple to configure:

- [Docs](https://tailscale.com/docs/how-to/quickstart)

And to manage:

- [Dashboard](https://console.tailscale.com/admin/machines)

Essentially:

- Create a tailscale account and use it for auth when adding devices and creating your initial network
- Go to the above dashboard and copy their add device commands. It's a 2 minute setup per device, dead simple.
